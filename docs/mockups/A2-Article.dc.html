Sinkhorn Distances:双対性で最適輸送を速く解く

はじめに

機械学習では、予測した分布と正解の分布がどれだけ離れているかを測りたい場面がよくあります。最適輸送は、分布の「形」まで考慮して比べられる強力な道具ですが、そのまま解くと計算が重いのが難点でした。

この記事では、Cuturi(2013)の Sinkhorn Distances を題材に、双対性とエントロピー正則化を使うと、最適輸送が行列とベクトルの掛け算の繰り返しだけで近似的に解けることを紹介します。

小麦をパン屋に運ぶ

工場 i には小麦が ai だけあり、パン屋 j は小麦を bj だけ必要としています。工場 i からパン屋 j へ1単位運ぶコストは Cij です。小麦は途中で消えたり増えたりせず、総量は1に正規化しておきます。

このとき、運ぶ量 Pij をどう決めれば総コストが最小になるか、というのが最適輸送問題です。

minP  Σi,j Cij Pij
s.t.  Pij ≥ 0,  Σj Pij = ai,  Σi Pij = bj

目的関数も制約も1次式なので、これは線形計画問題です。たとえば工場が2つ、パン屋が2つで、a = (0.5, 0.5)、b = (0.3, 0.7)、隣どうし(工場1とパン屋1、工場2とパン屋2)のコストが0、たすき掛けのコストが1とします。最適な計画は、工場1からパン屋1へ0.3、パン屋2へ0.2、工場2からパン屋2へ0.5を運ぶもので、総コストは0.2です。

見方を変える:双対問題

線形計画問題には、対になる双対問題があります。ここでは、輸送を請け負う業者の立場で考えてみます。業者は工場 i から1単位あたり fi の集荷料、パン屋 j から gj の配送料を受け取ります。

ただし料金の合計が自分で運ぶコスト Cij を超えると、工場とパン屋は業者に頼まなくなります。この条件のもとで、業者は売上を最大にしようとします。

maxf, g  Σi ai fi + Σj bj gj
s.t.  fi + gj ≤ Cij

制約を満たす P と f, g なら、いつでも次の不等式が成り立ちます(弱双対定理)。

Σ Cij Pij  ≥  Σ (fi + gj) Pij  =  Σ ai fi + Σ bj gj

主問題は上から、双対問題は下から最適値に近づき、最適解では両者が一致します(強双対定理)。双対問題の変数は n + m 個で、主問題の nm 個よりずっと少ないのがポイントです。

エントロピーで滑らかにする

制約を満たす P の集合は輸送多面体と呼ばれます。線形計画の最適解はその頂点に現れるため、a や C を少し変えただけで解が別の頂点へ飛ぶことがあり、微分を使った最適化と相性がよくありません。

そこで Sinkhorn Distances では、目的関数にエントロピー h(P) = −Σ Pij log Pij の項を加えます。

minP  Σ Cij Pij + ε Σ Pij log Pij

エントロピーは輸送量が均等に散らばるほど大きくなるので、この項は解を多面体の内側へ引き込みます。目的関数は狭義凸で滑らかになり、解はただ一つに決まります。ε を小さくするほど、元の問題の解に近づきます。

解の形を求める

供給と需要の制約に、ラグランジュ乗数として先ほどの f, g を割り当てます。

L = Σ Cij Pij + ε Σ Pij log Pij
+ Σi fi (ai − Σj Pij) + Σj gj (bj − Σi Pij)

Pij で偏微分して0とおくと、Cij + ε(log Pij + 1) − fi − gj = 0 より、

Pij = exp((fi + gj − Cij) / ε − 1) = ui Kij vj
ui = efi/ε − 1/2,  vj = egj/ε − 1/2,  Kij = e−Cij/ε

行列で書くと P = diag(u) K diag(v) です。K はコストだけで決まる固定の行列なので、nm 個の変数を持つ P を探す問題が、2本のベクトル u, v を探す問題に変わりました。

Sinkhornアルゴリズム

P の行和が a、列和が b になるように、u と v を交互に更新します。片方を固定すればもう片方は割り算一発で決まるので、双対変数を交互に最適化していることになります。

import numpy as np

def sinkhorn(a, b, C, eps, n_iter=1000):
    K = np.exp(-C / eps)
    u, v = np.ones_like(a), np.ones_like(b)
    for _ in range(n_iter):
        u = a / (K @ v)      # 行和を a に合わせる
        v = b / (K.T @ u)    # 列和を b に合わせる
    return u[:, None] * K * v[None, :]

a = np.array([0.5, 0.5])
b = np.array([0.3, 0.7])
C = np.array([[0.0, 1.0], [1.0, 0.0]])
P = sinkhorn(a, b, C, eps=0.5)
# [[0.288 0.212]
#  [0.012 0.488]]  総コスト 0.224

1回の更新は行列とベクトルの積だけなので、GPUで並列に計算しやすいのも利点です。ε = 0.1 まで小さくすると、解は元の問題の解(総コスト0.2)とほぼ一致します。

おわりに

双対性で変数をベクトル2本に減らし、エントロピー正則化で問題を滑らかにすることで、最適輸送は単純な反復計算で解けるようになりました。一方で、正則化した値は同じ分布どうしでも0にならないなど、厳密には距離の公理を満たしません。この点を補正した Sinkhorn divergence や、Wasserstein距離との関係は次回の記事で扱う予定です。
